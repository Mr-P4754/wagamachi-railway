# わがまちレールウェイ

名作箱庭・鉄道経営シミュレーションゲームをベースに、Three.js (WebGL) + TypeScript でフルリメイクした現代版3D鉄道・都市開発シミュレーションです。

ブラウザさえあれば、PC・スマートフォン・タブレット問わず、インストール不要でどこでもプレイできます。

---

## 🌟 主なリメイク特徴

1. **進化した3D立体感 & 美しいグラフィックス**:
   - Three.js によるリアルタイムPBRライティングとソフトシャドウ。
   - 地上線路（立体バラスト・枕木・鋼鉄レール・架線柱）やコンクリート高架橋・スラブ軌道の立体モデリング。
   - 昼夜サイクル（爽やかな昼間 ☀️、情緒的な夕景 🌅、窓が温かく発光する夜景 🌙）。
   - 住宅・オフィスビル・街路樹・道路網の生き生きとした街並み。

2. **前面展望（運転士カメラ）モード**:
   - 運行中の列車に乗り込み、運転台からの視点で敷設した線路や発展した街を眺めることができます。

3. **本格的な鉄道経営 & 都市自動発展**:
   - 直感的な線路敷設、地上駅・高架駅の建設。
   - 列車の購入・配置・ダイヤ運行（駅での自動停車、発車ベル、折り返し運行）。
   - 駅周辺の利便性向上により、空地から住宅、そして高層商業ビルへと街が自動発展するシミュレーション。
   - 運賃収入、建設費、月次維持費、年度決算レポート。

4. **Web Audio API によるプロシージャル鉄道サウンド**:
   - 列車走行音（ガタンゴトンというジョイント音）、警笛、発車ベルを完全シンセサイズ。外部音声ファイルのロード遅延ゼロで快適動作。

5. **安定動作 & GitHub Pages 完全対応**:
   - 旧来の32bit Windows / VC++ランタイムへの依存を完全排除。
   - ローカルストレージへのオートセーブ（自動保存）対応。
   - GitHubリポジトリに push するだけで、GitHub Pages（`.github/workflows/deploy.yml`）に自動公開されます。

## 🎮 操作方法

* **カメラ操作**:
  - **視点回転**: 左ボタンドラッグ（タッチ操作: 1本指ドラッグ）
  - **視点移動（パン）**: 右ボタンまたは中ボタンドラッグ
  - **ズーム**: マウスホイール（タッチ操作: 2本指ピンチ）
* **建設ツール（画面下部）**:
  - **選択/情報**: タイルをクリックして詳細情報を表示。
  - **線路 (地上 / 高架)**: クリックして線路を敷設。前後の接続に応じて自動で向きを判定。
  - **駅舎 (地上 / 高架)**: クリックして駅を開設。
  - **列車購入**: 線路または駅をクリックして新列車を配置。
  - **道路 / 住宅区画 / 商業ビル / 植林**: クリックして建設。
  - **撤去**: クリックした施設を解体・更地化。
* **上部・右側HUD**:
  - **速度変更**: ⏸一時停止 / ▶通常 (x1) / ▶▶高速 (x2) / ⏩超高速 (x4)
  - **🎥 視点切替**: 全体自由視点 ⇄ 列車前面展望（運転士視点）
  - **☀️ 昼夜切替**: 昼間 ⇄ 夕暮れ ⇄ 夜景
  - **📐 グリッド**: マップ方眼の表示/非表示
  - **📊 財務報告**: 今期の収支・純利益・都市指標の確認、手動セーブ、更地リセット

## 🚀 GitHub Pages への公開手順

1. 本リポジトリを GitHub の任意のリポジトリ（例: `https://github.com/<your-username>/wagamachi-railway`）に push します。
2. GitHub のリポジトリ設定画面（**Settings** > **Pages**）を開きます。
3. **Build and deployment** の **Source** を **GitHub Actions** に設定します。
4. これにより、同梱されている `.github/workflows/deploy.yml` が自動実行され、数分で `https://<your-username>.github.io/<repo-name>/` にゲームが公開されます！

## 💻 ローカル開発

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (http://localhost:3000)
npm run dev

# プロダクションビルド
npm run build
```
