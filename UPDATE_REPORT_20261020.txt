================================================================================
わがまちレールウェイ（Wagamachi Railway）
アップデート・不具合修正レポート（2026年10月20日）
================================================================================

【概要】
セーブ＆ロード時の地形・シード値の永続化、タイトル画面遷移の安定化、
シミュレーションの整合性向上、列車カメラ追従、スロープの階層間衝突防止、
およびUndo（元に戻す）操作の完全同期など、合計10件以上の不具合修正と挙動改善を実施しました。

--------------------------------------------------------------------------------
1. 地形・セーブ＆ロード（PersistenceService / GridManager）
--------------------------------------------------------------------------------
- 【地形変動バグの修正】
  - セーブデータ（world_meta）に terrainSnapshot（全マスの標高・水域情報）を永続化保存・復元する機能を追加。
  - 初回ゲーム起動時（新規都市生成時）に即時確定セーブを実行し、乱数シードの欠落を防止。
  - ミニマップの地形背景（rebuildBackground）をロード時に再描画同期。
- 【「資金無限モード」状態の永続化】
  - SavedEconomyRecord に isInfiniteFunds を追加し、リロード後もON/OFF状態とUIスイッチ状態を完全保持。
- 【都市初期化（リセット/新規作成）時の表示モード初期化】
  - resetGame() および startNewGame() 実行時、X-Ray透過モード、昼夜照明モード（auto・朝6:00）、ミニマップ物流モードを確実に初期状態へリセット。

--------------------------------------------------------------------------------
2. UI・タイトル画面（index.html / UIManager）
--------------------------------------------------------------------------------
- 【タイトル画面「✕」ボタンの廃止と二重生成防止】
  - タイトル画面右上の「✕」ボタン（#btn-title-close）を廃止し、必ず「新規作成」または「つづきから」を選択するフローに統一。
  - 新規作成・リセット時の既存オブジェクト（タイル・列車・台帳・ゾーン）完全消去ガードを追加し、列車の重複増殖を防止。

--------------------------------------------------------------------------------
3. 線路敷設・スロープ・干渉防止（WorldMap / PlacementController）
--------------------------------------------------------------------------------
- 【スロープの上下階層空中衝突防止】
  - 高架スロープ（rail-slope）および地下スロープ（rail-slope-underground）の4マス全域について、敷設時・仮置き時に開始階層だけでなく上位階層（upperLayer）および地下階層（-1）の既存線路・建物・在線列車・仮置きとの衝突判定を追加。
  - getItemTargetPositions および executePlacement において4マス全域の階層をターゲットに含め、Undo時の巻き戻しも完全化。

--------------------------------------------------------------------------------
4. 列車運行・カメラ制御（TrainManager / FleetController / main.ts）
--------------------------------------------------------------------------------
- 【マップ外直通列車の走行音スキップ】
  - 隣町直通中（externalTravel）の列車に対して、マップ外走行中のジョイント音再生をスキップ。
- 【車窓・追従カメラ終了時の追従ターゲット解除】
  - 車窓モード（exitCabView）終了時、対象列車がマップ外走行中の場合は追従ターゲット（selectedTrainId / cabTargetTrainId）をクリアし、カメラの境界強制ロックや帰還時の予期せぬカメラワープを防止。
- 【保有車両管理からの追跡ガード】
  - 車両基地モーダルからマップ外走行中の列車を「追跡」した際、カメラの境界ジャンプを防止し、「マップ外走行中」のトースト案内を表示。

--------------------------------------------------------------------------------
5. シミュレーション・需要・Undo整合性（CityGrowth / UndoManager / InteractionController / main.ts）
--------------------------------------------------------------------------------
- 【都市発展（CityGrowth）のリロード時多重実行防止】
  - syncTime(day, hour) メソッドを追加し、セーブ・ロード後や新規開始時にカレンダー日と評価時刻（12:00基準）を同期。同一日の重複発展を防止。
- 【手動撤去・配置・Undo時の需要エンジンキャッシュ即時同期】
  - タイル手動撤去時、新規配置確定時、および Undo 実行後に demandEngine.clearCache() を即時実行し、撤去した建物や新設駅の魅力度・地価キャッシュをリアルタイムに更新。
- 【駅撤去Undo時のデータ整合性】
  - 駅撤去のUndo時、ホームタイルのソート順序を保証し、プラットフォーム登録とタイル情報の整合性を維持。
- 【貨物ヤード指定ツールのUndo対応】
  - 「貨物ヤード指定（cargo-yard）」ツール使用時、同一ホームに属する全タイルを一括でヤード化し、Undoスタックに登録して Ctrl+Z での解除・返金に対応。
- 【分岐器モード変更時の自動保存とシーサス連動】
  - インスペクターからの分岐器動作モード（手動/交互/タイムライン）変更時、自動保存のダーティフラグを立て、シーサスクロッシング4マスの設定を自動同期。
