操作ガイド・ヘルプ

基本操作・カメラ移動

  • 選択・建設: 左クリックで施設選択や単発配置。線路・道路は左ドラッグで長距離の一括敷設とL字カーブ補間が可能
  • 向きの回転: 右クリック または Rキー で設置向きを回転。仮置き確定は Enter、取消は Esc、元に戻すは Ctrl+Z
  • 視点移動・ズーム: 右ドラッグ / 中ドラッグ / WASD・矢印キー（選択ツール時は左ドラッグも可）。ホイールまたはピンチでズーム
  • カメラ回転: Q / Eキー または画面右の回転ボタンで90度ずつ回転。コンパスクリックで北向きにリセット
  • 時間速度・資金無限: 数字キー 0〜5 で時間速度切替。ヘッダーの資金クリック または Mキー で資金無限モード切替

立体建設・分岐・信号システム

  • 全7階層スライサー: 画面左の B2〜5F ボタンで建設・表示階層を切替。水辺は2F以上の鉄橋か地下トンネルで通過可能
  • 勾配・トンネル: 勾配線路は4マスで1階層分昇降。山岳に向かって1Fで線路を引くと自動的に山岳トンネルが開通
  • 自動分岐・シーサス: 既存の直線レールから別方向へドラッグすると自動で分岐器に変換。複線には2×2マスのシーサスクロッシングも設置可能
  • 閉塞信号・待避施設: 線路は閉塞区間で保護され、先行列車がいる区間へは手前で自動停止。コストを抑えた待避には「信号場・留置線」が有効

ダイヤ編成・車両運行

  • 24時間タイムラインダイヤ: 駅や分岐器を選び Dキー または「ダイヤ設定」から、発車時刻ピン・等間隔パターンダイヤ・通過時間帯・折り返しを設定
  • 分割・併合: 駅ダイヤで「分割」を有効にすると到着編成を前後に切り離し可能。停車中の編成があるホームに後続が進入すると自動で連結
  • 系統テンプレート: 作成したダイヤは「系統として保存」し、路線内の複数駅・ホームへ一括適用可能
  • 車両基地と車窓: 「列車」メニューから車両を購入し線路へ配置。列車クリックで追従カメラや運転席からの前面展望に切替可能

都市発展・貨物物流・隣町直通

  • 乗降客と街の成長: 駅の1日あたり乗降客数（100人 / 1,000人 / 5,000人 / 10,000人）に応じて、駅周辺の建物数とビル高層化の上限が段階的に解放
  • 貨物サプライチェーン: 工業施設で毎日17時に生産されるコンテナを、工業エリアの貨物駅から商業エリアの貨物駅へ貨物列車で運ぶと、高収入とともに商業魅力度と旅客需要が大幅に上昇
  • 隣町との広域直通: マップ東西南北の境界端まで線路を伸ばすと、隣町（新東都・北ノ森・南港・西条重工）と直通開通し、マップ外との長距離旅客・貨物往来が開始
